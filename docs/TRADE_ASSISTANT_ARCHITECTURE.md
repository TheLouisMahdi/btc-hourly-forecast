# Trade assistant architecture

## Product contract

The repository is a decision-support research system, not an autonomous execution engine.

The primary public model remains the exact next closed one-hour candle direction forecast. Paper positions are a secondary research contract and are not considered production-qualified merely because the one-hour forecast performs well.

## Decision hierarchy

```text
Closed hourly market data
        |
        +--> Primary 1h direction model
        |       +--> guarded online support
        |       +--> live/static pattern-memory confidence adjustment
        |       `--> immutable next-candle outcome ledger
        |
        `--> Deterministic structural event
                +--> continuation model
                +--> tradeability model
                +--> expected event return
                +--> explicit false-breakout meta model
                +--> exact-count + Bloom pattern memory
                `--> precision meta gate
                         |
                         +--> SKIP / WAIT
                         `--> qualified paper position
                                +--> horizon-aligned target
                                +--> MFE/MAE-aligned stop
                                +--> historical breakeven/trailing profile
                                `--> immutable outcome learning
```

## Primary one-hour forecast

The one-hour direction model remains independent from position qualification. Pattern memory may reduce confidence when a repeated historical context has produced wrong forecasts or false structural breaks, but memory cannot reverse the direction by itself.

Every memory adjustment is bounded and moves probability toward 0.5 only. This preserves the direction model's role while allowing resolved mistakes to influence later confidence.

## Cross-layer pattern memory

Pattern memory has two layers.

### Static false-breakout memory

`pattern_memory.py` learns deterministic fingerprints from training rows labeled by `false_breakout_h1`, `false_breakout_h3`, `false_breakout_h6` and `false_breakout_h12`.

A Bloom filter is used only as a fast membership structure. A hit is never trusted by itself. Exact per-fingerprint counts and bad rates must also satisfy the configured minimum repetition and bad-rate thresholds.

The fingerprint includes the structural direction and horizon plus causal event-candle context: body, range, upper/lower wick pressure, close location, the two previous candles, three-bar movement, volume change, event score and structure scale.

### Live one-hour mistake memory

Resolved next-candle outcomes are learned persistently on the `adaptive-state` branch. Only forecasts with complete causal candle context are eligible. A context becomes a bad live pattern only after repeated observations meet the configured count and wrong-rate gates.

## Precision meta gate for positions

A structural LONG or SHORT is a candidate, not an entry.

The precision meta filter is trained from chronological out-of-fold predictions generated by the primary structural model. Its inputs include:

- primary continuation probability,
- primary tradeability probability,
- primary predicted event return,
- out-of-fold one-hour direction confidence,
- event score and structure scale,
- the event candle and two prior closed candles.

The meta layer trains two classifiers per direction/horizon:

- probability that the candidate should be taken,
- probability that the breakout is false.

Thresholds are selected on a chronological calibration segment with a precision-first objective. Qualification is then evaluated on a later locked holdout. A head is not usable for new positions unless it satisfies the configured minimum selected count, minimum precision, maximum false-breakout acceptance and positive mean net return.

If no head qualifies, the one-hour forecast continues normally while new paper positions remain blocked as experimental.

## Horizon-aligned exits

Future meta-qualified positions no longer inherit a fixed 5R / 72-hour contract.

For each qualified direction/horizon, the exit profile is derived from historical successful events:

- target distance uses the configured horizon target bounded by successful MFE,
- stop distance uses historical adverse excursion and structural invalidation,
- breakeven and trailing triggers use successful MFE behavior,
- maximum holding time equals the selected training horizon.

Risk sizing and expected-value economics are recalculated after the final target/stop profile is applied.

An already-open position is immutable. Architecture upgrades never retroactively move its target, stop or expiry.

## Promotion contract

Heavy retraining remains on demand. A challenger can be promoted only after the existing economic and negative-memory gates pass and at least one precision meta head also passes its locked holdout gate.

Candidate diagnostics are retained even when promotion is rejected. The incumbent champion is preserved on any assistant-training failure.

## State ownership

- `model-state`: champion model, static negative memory, precision meta filter and static false-pattern memory.
- `adaptive-state`: online price learner, online trade learner and live next-candle pattern memory.
- `forecast-state`: immutable forecast history, position ledger and dashboard candle state.

No synthetic candle is created to repair a missing GitHub Actions run. Runtime recovery continues from real closed market candles.
